# 媒体识别与整理增强 PRD（v3 · 根因收敛）

> 撰写人：主理人（齐活林）代笔（产品经理子代理环境不可用）。基于三路只读代码勘察（整理/CSF、搜索识别、搜索-下载整理链路）。
> 关联分支：`v2`（已含"订阅 tmdbid 兜底回填 + 跨身份去重"修复，本 PRD 不破坏订阅链路）。
> 日期：2026-07-28

## 0. 范围（用户澄清 + 勘察结论）
- **不做订阅扩展**：推荐/探索页（基于 TMDB/豆瓣）没有的内容不需要订阅；订阅维持只对已识别媒体生效。
- **核心诉求**：搜一个标题（如短剧）→ 下载 → 进媒体库，这条路对平台未收录内容要通。
- **真正根因（收敛后）**：搜索（按关键词搜种子）本身可用；硬阻断在**整理(transfer)强依赖外部识别**、缺少"仅用文件名 MetaInfo 直接整理"的兜底，以及下载入口 `/download/add` 的识别强依赖。订阅链路不受影响。

## 1. 产品目标
让"搜索标题 → 下载 → 整理进媒体库"链路能服务于 TMDB/豆瓣未收录的短剧/自制内容：搜得到的种子能下、下完能用原文件名解析出的季/集信息整理进库（带规范 `SxxExx` 命名），使 ChineseSubFinder 与媒体服务器能识别季集。

## 2. 用户故事
- **US-1（搜索/下载）**：用户搜一个 TMDB/豆瓣都搜不到的短剧名，能拿到种子并直接下载，不被"未识别到媒体信息"挡住。
- **US-2（整理/字幕）**：短剧下载后能被正常整理进媒体库（而非因识别失败滞留），整理出的文件名带 `SxxExx`，使 CSF 认出第几季第几集。
- **US-3（兼容）**：现有 TMDB/豆瓣订阅与整理行为不回归。

## 3. 需求池（收敛后）

### 核心修复：整理兜底（覆盖原问题 A 与 B 的实质）
> 根因代码：`app/chain/transfer.py:1694-1748`（识别失败即 `return False,"未识别到媒体信息"`）；`app/modules/filemanager/transhandler.py:298-311`（TV 无 begin_episode 硬拒）；`app/api/endpoints/download.py:116-133`（/download/add 识别失败硬拒）。

| 优先级 | 编号 | 需求 | 用户价值 | 验收标准 |
|--------|------|------|----------|----------|
| P0 | C-1 | **transfer 增加文件名兜底**：当 `recognize_by_meta` 失败（无 tmdb/douban/bangumi id 且无订阅）时，用下载文件名解析出的 `MetaInfo`（title/type/season/episode）直接构造 `MediaInfo`(tmdb_id=None) 继续走 `transhandler` 重命名，而非一律判失败 | 短剧下完能进媒体库 | 一个"文件名带 S/E"的短剧种子，下载→整理→进库全链路通；整理历史不再报"未识别到媒体信息" |
| P0 | C-2 | **放开 `/download/add` 识别强依赖**：识别失败时允许继续下载（落 unsorted 或按 type），不报"无法识别媒体信息"硬阻断 | 下载阶段不因无 tmdb 卡死 | 走 `/download/add` 下短剧种子，不再返回"无法识别媒体信息" |
| P0 | C-3 | **整理命名规范**：兜底 MediaInfo 的命名沿用现有 `RENAME_FORMAT`，产出带 `SxxExx` 的文件（来自文件名 MetaInfo） | CSF/媒体服务器能识别季集 | 整理后路径含 `Season x/剧名 - SxxExx` |
| P1 | C-4 | **TV 无集号兜底策略**（见决策 Q1）：当文件名也无 begin_episode 时，按所选策略处理（当电影 / 强制 S01E01 / 手填），避免 `transhandler:298` 硬拒 | 无集号文件也能进库 | 一个"文件名完全无集号"的 TV 样例，按策略进入目标目录 |

## 4. 决策记录（用户拍板）
- **Q1 TV 无集号兜底策略**：**当电影处理**（识别失败且文件名也无集号时，整包当电影归入电影目录）。
- **Q2 手动媒体 media_id 规则**：`name+year` 哈希自动生成（用于 C-5 稳定键）。
- **Q3 前端入口**：先后端 API 支撑，**不做前端"手动添加"入口**。
- **Q4 能力边界**：MP 仅保证产出带 S/E 与 tmdbid(若有) 的文件/NFO；CSF/媒体服务器侧匹配不在范围。

## 5. 技术约束
- 只改项目仓库代码，**绝不触碰运行容器/NAS 数据库**，不主动推送（交付后由用户部署）。
- 公开方法需中文 docstring；尽量不加数据库迁移（复用现有列）；测试不得做真实网络/真实 DB 调用。
- 与已有订阅修复兼容；**订阅链路改动最小化**（本次主改 search/download/transfer）。

## 6. 范围边界
- **解决**：搜索-下载-整理对平台未收录内容可用（transfer 文件名兜底 + 放开下载识别强依赖 + TV 无集号兜底）。
- **不解决**：订阅添加 manual 源（用户明确不需要）；CSF 自身算法；媒体服务器配置；CSF 在 TMDB/TheTVDB 找不到中文短剧时的匹配。
